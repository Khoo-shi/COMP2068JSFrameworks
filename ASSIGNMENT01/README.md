# COMP 2068 Assignment 1 – Personal Portfolio Website

## Description

This is a personal portfolio website created for COMP 2068 Assignment 1 using Express.js and the Handlebars (HBS) templating engine.

The website includes four pages:

* Home
* About Me
* Projects
* Contact Me

The goal of this project is to showcase my background, technical skills, projects, and contact information in a professional and responsive website.

## Technologies Used

* Node.js
* Express.js
* Handlebars (HBS)
* Bootstrap 5
* HTML5
* CSS3
* Git and GitHub

## Features

* Responsive design
* Shared layout with navigation and footer
* Professional pink and cream colour scheme
* GitHub and LinkedIn links in the footer
