# LocalLink

LocalLink is a community resource directory built using Node.js, Express, MongoDB, Mongoose, and Handlebars. The application allows users to browse local community services and enables authenticated users to manage resources.

## Features

- User Registration
- User Login
- GitHub Login
- Create, Read, Update, and Delete (CRUD) operations
- Public Resource Directory
- Protected Resource Management
- Keyword Search (Additional Feature)

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Handlebars (HBS)
- Bootstrap 5
- Passport.js
- GitHub OAuth
- Express Session

## Additional Feature

A keyword search feature has been implemented that allows users to search resources by name, category, or city.
